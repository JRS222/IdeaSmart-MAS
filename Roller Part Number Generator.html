Microroll / InfiniDrive — Relationship & History
Corporate note: InfiniDrive Motor Manufacturing (Grand Rapids, MI) acquired Microroll's roller division. Microroll RC-format and InfiniDrive RD-series part numbers are positionally identical — a Microroll RC-format part number can be reordered as an InfiniDrive RD-series part.

What this means for you

  • Both brands use the same 10-character positional format plus a trailing specials character.
  • Diameter codes are shared: A=48, B=50, C=57, D=60, E=63.
  • Source & power codes are shared: D000 (idler), D032 (22 W), D042 (35 W), DU42 (35 W UL), DB32 (22 W brake), DB42 (35 W brake).
  • Both brands use JST XHP-10 connectors for standard rollers.
  • InfiniDrive's own driver card line (C100, C100Z, C166ZB) replaces the older Microroll cards.

Legacy Microroll part numbers

The compact MR-… format you may see in older databases is Microroll's pre-acquisition syntax. It still maps 1:1 to the positional format — see the "Legacy Microroll Format" section.

Microroll / InfiniDrive — Installation & Torque

Threaded Shaft Installation (RD48–RD63)

  1. Prepare motor connector: tilt 90°, twist until wires are taut.
  2. First nut + lock washer are pre-installed on shaft. Feed connector through frame hex hole.
  3. Depress spring-loaded shaft, insert into opposite rail hex hole.
  4. Insert wires through second lock washer + retaining nut.

Legacy Microroll — Compact MR Format

The compact MR-… format predates the positional system. It is still accepted for reorders and appears in older inventories (including your workbook's ROLLER DB).

MR-AD-48-296-10YWGY
 │  │   │   │ │ │ │
 │  │   │   │ │ │ └── Q = variant suffix
 │  │   │   │ │ └──── Grooves (A = pulley, G = standard)
 │  │   │   │ └────── τ (W = standard, Z = up-spiral)
 │  │   │   └──────── Speed code
 │  │   └──────────── Tube length (mm)
 │  └──────────────── Braking (B = down-spiral, A = none)
 └─────────────────── MR = Microroll series
